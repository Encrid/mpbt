# src/shared/sha256/sha256.h

This header declares the state of a SHA-256 digest, and the functions that make the digest.
`fetch` checks each download with it, and `compose` writes the lines of `package.txt` with it.

## sha256_t

| Field | Value |
| --- | --- |
| `state` | The 8 words of the hash, each a `uint32_t`. |
| `length` | The count of the bytes that were added. |
| `block` | 64 bytes: the block that is not full yet. |
| `used` | The count of the bytes in `block`. |

## Functions

| Function | Result |
| --- | --- |
| `sha256_start` | Starts a digest with no byte. |
| `sha256_add` | Adds bytes to a digest. |
| `sha256_end` | Gives the 32 bytes of the digest. |
| `sha256_get_hex` | Gives the 64 hexadecimal characters of 32 bytes. |
