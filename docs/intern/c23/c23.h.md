# src/c23/c23.h

This header gives the constants, the types and the shared functions of the check `c23`.

## The constants

| Constant | Value |
| --- | --- |
| `C23_SLOT_FILE`, `C23_SLOT_FINDING` | 0 and 1: the slots of `mpbt:File` and of `mpbt:Finding`, in the order of `init`. |
| `C23_WINDOW` | 5: the tokens of the longest form of the code, for example `(void)name;`. |

## c23_run_t

| Field | Value |
| --- | --- |
| `api` | The table of BB-Native. |
| `place` | The `finding_t` that `finding_format` gets: `mpbt:Finding` by its slot, `c23` as the check, and the path of the `mpbt:File`. |
| `file` | The `mpbt:File` under check. |

The run is on the stack of the system. The check takes no memory of the heap, and `finding_format` of `src/shared/finding/finding.h` takes none either.

## c23_window_t

| Field | Value |
| --- | --- |
| `tokens` | The last `C23_WINDOW` tokens of the code, the oldest first. |
| `count` | The count of the tokens in `tokens`. |

A window holds only names, numbers, strings, characters and marks.
The code and each directive have windows of their own. Thus a form never joins the tokens of a directive to the tokens of the code.

## c23_spelling_t

An older spelling that is a name, in the table of `src/c23/c23_spellings.c`.

| Field | Value |
| --- | --- |
| `name` | The older name, for example `_Bool`. |
| `newer` | The newer spelling of the name in `docs/extern/mpbt_check.h.md`, *c23*. |
